# 덕메 시연 대사 (실제 데이터 버전)

데이터: 손민수위키 제품 63개(NCT WISH·Stray Kids, 실제 검수 데이터) + 시연용 예시 대체템 7개(isSample) / reCree 장소 521곳(실제 위도·경도, 팬덤 성지 443곳, 공개 글 438곳).
시연 전: 브라우저 새로고침 → "기억 초기화".

1. 첫인사 (기억)
   > 안녕! 나 위시 시온 최애야. 옷은 M, 예산은 보통 3만 원 정도야
   → 기억 패널: 최애 NCT WISH 시온, 사이즈 M, 예산 3만

2. 착용템 찾기 (별명 + 검색 + 대체템)
   > 오시온이 인천공항에서 쓴 갈색 코듀로이 모자 비슷한 거 찾아줘
   → 원래 제품: 프라다 코듀로이 캡 480,343원 (손민수위키 검수)
   → 대체템(예시): 무신사 스탠다드 1.99만 / 커버낫 3.2만 / MLB 3.9만

3. 찜 + 성지 코스 (Tool 2개 + 지도)
   > 무신사 스탠다드로 찜! 이번 주말에 목포 가는데 시온 따라가는 코스 짜줘
   → 목포 코스: 시온 단골 '황금어장'(굴비회정식), 커피창고로(시온 픽 에그타르트), 코롬방제과점(위시 픽 새우바게트) 등, 지도에 번호 핀
   → 장소 카드에 '위시 픽 메뉴'(mustTry)와 reCree 링크
   (목포는 시온 고향, 자컨 '목포로 오시온' 촬영지 9곳이 실제 데이터에 있음)

4. 서버 재시작 → 새로고침 (기억 유지 보여주기)

5. 구매·방문 후기 (보유·방문 반영 + 축하 표정 + 다음 추천)
   > 그 모자 샀어!! 목포도 다녀옴 ㅎㅎ
   → 보유템 +1, 방문 성지 반영, 🎉
   → 다음 추천 예: 시온 파르티멘토 브라운 레더 퀄티드 자켓 110,900원 (브라운 모자랑 톤 맞춤)

6. 한계 처리 (지어내지 않기)
   > 시온이 어제 신은 운동화 뭐야?
   → 데이터에 없으면 "아직 확인되지 않은 정보" + 손민수위키에 질문 남기기 안내

예비 대사 (심사위원이 다른 걸 물을 때)
- "리쿠가 멘 휴먼메이드 백팩 비슷한 거 5만 원 안으로" → 휴먼메이드 밀리터리 백팩 234,510원 + 대체템 2개
- "유우시 숏폼에서 입은 회색 나이키 후드" → 나이키 클럽 플리스 풀오버 109,000원 + 대체템 2개
- "전주 가는데 위시 갔던 데 알려줘" → 풍년제과, 꽃담집, 전주 한복남
